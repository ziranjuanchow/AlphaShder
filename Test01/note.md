# 重心坐标计算，及用处

## 主体

重心坐标是描述一个点相对于三角形各顶点位置的重要工具，在计算机图形学、几何计算和物理模拟中非常有用。下面我们来看看如何通过向量法计算重心坐标。

### 🔺 理解重心坐标

想象一个由三个顶点 A, B, C 构成的三角形。平面内的任意一点 P 的位置，都可以表示为这三个顶点位置的加权平均：

**P = u × A + v × B + w × C**

这里的 (u, v, w) 就是点 P 的重心坐标，并且它们满足归一化条件：**u + v + w = 1** 。

重心坐标有清晰的几何意义：每个坐标值等于点P与对应顶点所对边形成的子三角形的面积与整个三角形面积的比值。例如，u 等于子三角形△PBC的面积与整个三角形△ABC的面积之比 。

根据重心坐标的值，可以判断点P与三角形的位置关系 ：

* **在三角形内部**：当且仅当 u, v, w 均大于0且小于1。
* **在边上**：其中一个坐标为0，其余两个在0到1之间。
* **在顶点上**：其中一个坐标为1，其余两个为0。
* **在三角形外部**：存在负的坐标值。

### 🧮 向量法计算重心坐标

基于向量运算的方法可以直接计算出重心坐标。核心思路是将几何问题转化为向量方程求解 。

1. **建立向量方程**

   由重心坐标的基本定义 P = uA + vB + wC 和 u + v + w = 1，可以将公式变形，将点P的位置表示为从顶点A出发，沿边AB和AC方向的向量组合：

   **P - A = v(B - A) + w(C - A)**

   令 **v0 = B - A**，**v1 = C - A**，**v2 = P - A**，则方程简化为：

   **v2 = v × v0 + w × v1**
2. **利用点积构造方程组**

   为了求解v和w，将上述向量方程两边分别与向量v0和v1进行点积运算，得到一个二元一次方程组 ：

   ```
   v2 · v0 = v × (v0 · v0) + w × (v1 · v0)
   v2 · v1 = v × (v0 · v1) + w × (v1 · v1)
   ```
3. **定义点积并应用克莱姆法则**

   令：

   * `d00 = v0 · v0`
   * `d01 = v0 · v1`
   * `d11 = v1 · v1`
   * `d20 = v2 · v0`
   * `d21 = v2 · v1`

     分母 `denom = d00 × d11 - d01 × d01`

     则v和w的解为：
   * `v = (d11 × d20 - d01 × d21) / denom`
   * `w = (d00 × d21 - d01 × d20) / denom`

     最后求出u：
   * `u = 1.0 - v - w`

### 💻 代码实现示例

以下是一个简单的代码框架，展示了如何用编程语言实现上述计算过程（以类C语法为例）：

```
// 假设已有二维向量 Vector2 及其点积函数 Dot
void Barycentric(Vector2 A, Vector2 B, Vector2 C, Vector2 P, float& u, float& v, float& w) {
    Vector2 v0 = B - A;
    Vector2 v1 = C - A;
    Vector2 v2 = P - A;
  
    float d00 = Dot(v0, v0);
    float d01 = Dot(v0, v1);
    float d11 = Dot(v1, v1);
    float d20 = Dot(v2, v0);
    float d21 = Dot(v2, v1);
  
    float denom = d00 * d11 - d01 * d01;
    // 注意：检查 denom 是否为0（三角形退化情况），实际应用中需处理
    v = (d11 * d20 - d01 * d21) / denom;
    w = (d00 * d21 - d01 * d20) / denom;
    u = 1.0f - v - w;
}
```

### 🧠 核心应用场景

重心坐标凭借其特性，在多个领域有广泛应用：

* **点在三角形内的判断**：这是重心坐标最直接的应用之一。通过计算点P相对于三角形ABC的重心坐标，并检查u, v, w是否均非负，即可高效判断点是否在三角形内部 。
* **图形学中的插值**：在三角形面片上进行平滑着色（Gouraud着色）、纹理映射或计算法向量时，可以先在三个顶点计算所需属性（如颜色、纹理坐标、法线），然后利用重心坐标作为权重，在三角形内部进行线性插值。因为重心坐标具有仿射不变性，这样插值的结果是平滑且准确的 。
* **三角形重心**：三角形的几何重心（三条中线的交点）的重心坐标是 (1/3, 1/3, 1/3) 。

### ⚠️ 注意事项

* **退化三角形**：在实际计算中，需要检查分母 `denom`是否接近零。如果为零，意味着三个顶点共线，三角形退化，无法计算有效的重心坐标 。
* **计算效率**：该方法涉及多个点积运算，但计算量固定，效率很高，非常适合在需要大量此类计算的图形渲染管线中使用 。

### 📚 进阶扩展

上述向量法主要适用于二维平面上的三角形。对于三维空间中的点P和三角形ABC，方法类似。通常可以将三维点P和三角形ABC投影到一个二维坐标系（如三角形所在平面）上再进行计算，或者直接使用三维向量点积和叉积来求解，原理相通。

## 解释点

重心坐标需要满足归一化条件（即 u + v + w = 1），这并非随意规定，而是源于其深刻的几何意义和在数学上保持**仿射不变性**的必然要求。为了让你快速把握核心要点，下表对比了满足与不满足归一化条件时的关键差异。

| 对比维度             | 满足归一化条件 (u+v+w=1)                                       | 不满足归一化条件 (u+v+w≠1)                                  |
| -------------------- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| **几何意义**   | 点P严格位于由A, B, C确定的二维平面上。                         | 点P会偏离ABC所在的平面，坐标失去对三角形内点位置的描述能力。 |
| **坐标系统**   | 是**二维**的（因一个坐标可由另两个导出），参数是唯一的。 | 坐标系统维度混乱，表示不唯一，同一平面点可有多种权重组合。   |
| **位置判断**   | 可直接用于判断点与三角形关系（如内部、边上、外部）。           | 无法直接根据坐标值判断点与三角形的相对位置。                 |
| **插值稳定性** | 插值结果具有**仿射不变性**，不依赖于坐标系的选择。       | 插值结果会因坐标系变换（如平移、旋转）而改变，不稳定。       |

### 为什么满足归一化

#### 💡 深入理解归一化的必要性

归一化条件 `u + v + w = 1`的核心作用在于将点的表示“锚定”在由三角形顶点所张成的特定二维空间（即三角形所在平面）内。

1. **维持仿射不变性**

   这是归一化条件最重要的作用之一。仿射不变性意味着，当你对整个三角形（包括其顶点和内部的点）进行平移、旋转、缩放等仿射变换时，点P相对于该三角形的重心坐标 `(u, v, w)`保持不变。这是因为归一化条件将点的表示与顶点的绝对位置解耦，只关心点相对于三个顶点的相对比例关系。这使得重心坐标成为一个非常稳健的工具，广泛应用于图形学中的属性插值。
2. **简化计算与唯一性**

   归一化条件 `u + v + w = 1`消除了一个自由度。理论上，我们需要三个坐标来确定一个三维空间中的点，但因为这个约束条件的存在，我们实际上只需要两个独立的坐标（比如 `v`和 `w`）就能唯一确定点P在平面上的位置，第三个坐标可以通过 `u = 1 - v - w`算出。这不仅简化了计算，也保证了在给定三角形和平面内一点P时，其归一化的重心坐标是唯一的。

#### 💎 总结与应用启示

归一化条件 `u + v + w = 1`是重心坐标系统的基石。它确保了：

* **几何正确性**：点被正确约束在三角形所在平面。
* **系统唯一性**：平面内每一点有且仅有一组归一化重心坐标。
* **应用可靠性**：基于重心坐标的插值和位置判断是稳定且准确的。

在实际应用中，例如进行颜色、纹理坐标或法线等属性在三角形面上的插值时，务必确保使用的重心坐标是归一化的，才能得到正确、平滑的插值结果。

### 克莱姆法则


克莱姆法则是线性代数中一个关于求解线性方程组的定理，由瑞士数学家加布里埃尔·克莱姆（Gabriel Cramer）在其1750年发表的《线性代数分析导言》中明确阐述并推广。尽管历史资料显示，德国数学家莱布尼茨和英国数学家马克劳林更早已知晓该法则，但克莱姆因其优越的记法使其广为流传。

下面这个表格能帮你快速抓住克莱姆法则的要点：

| 特性               | 描述                                                                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **核心用途** | 求解 **n元线性方程组** (方程个数与未知数个数必须相等)                                                                                       |
| **核心公式** | **x**j=**D**D**j**，其中**D**是系数行列式，**D**j是常数项替换**D**中第**j**列后得到的行列式             |
| **适用前提** | 1. 方程组是线性的（未知数均为一次）``2. 方程个数等于未知数个数``3. **系数行列式**D****=**0** (这是解唯一的前提) |
| **主要价值** | **理论价值突出**，清晰地揭示了解的存在性、唯一性与系数行列式之间的直接关系                                                                  |
| **主要局限** | **计算效率低**，当未知数较多时（n>3），计算量巨大，实用性差                                                                                 |

### 🔍 理解法则内容

对于一个包含 **n**个方程和 **n**个未知数的线性方程组，其标准形式如下：

```
⎩⎨⎧a11x1+a12x2+⋯+a1nxn=b1a21x1+a22x2+⋯+a2nxn=b2⋮an1x1+an2x2+⋯+annxn=bn
```

克莱姆法则指出，如果方程组的**系数行列式** **D**（由所有系数 **a**ij构成的 **n**阶行列式）不等于零，那么该方程组有**唯一解**。这个唯一解中的每个未知数 **x**j可以通过一个简洁的公式求出：

```
xj=DDj
```

其中，**D**j是将系数行列式 **D**中的第 **j**列元素替换为方程组的常数项 **b**1,**b**2,**…**,**b**n后所构成的新行列式。

### ⚠️ 明确适用前提

使用克莱姆法则前，务必检查是否满足以下所有条件：

* **方程组必须是线性的**：即每个方程中的未知数均为一次幂。
* **方程个数必须等于未知数个数**：这样系数矩阵才是方阵，才能计算行列式。
* **系数行列式 **D****=**0**：这是克莱姆法则适用的**最关键条件**。如果 **D**=**0**，则法则失效，无法通过该公式求解。此时，方程组可能无解，也可能有无穷多解。

### 🧩 计算步骤与示例

以一个简单的二元一次方程组为例：

```
{2x+3y=74x−y=1
```

1. **计算系数行列式 **D****:

   ```
   D=243−1=(2×−1)−(3×4)=−2−12=−14(=0)
   ```

   因为 **D****=**0，所以方程组有唯一解，可以应用克莱姆法则。
2. **计算 **D**x****和 **D**y**:

   * **D**x是用常数项（7和1）替换 **D**中 **x**的系数（第一列）：

     ```
     Dx=713−1=(7×−1)−(3×1)=−7−3=−10
     ```
   * **D**y是用常数项替换 **D**中 **y**的系数（第二列）：

     ```
     Dy=2471=(2×1)−(7×4)=2−28=−26
     ```
3. **求解 **x**和 **y****:

   ```
   x=DDx=−14−10=75,y=DDy=−14−26=713
   ```

### ⚖️ 优缺点与价值

克莱姆法则的优缺点非常鲜明：

* **优点与理论价值**：

  * **直观清晰**：公式明确表达了方程组的解与系数、常数项之间的直接关系。
  * **理论重要**：是线性代数中的重要定理，常用于理论推导和证明，例如判断解的唯一性。
* **缺点与局限性**：

  * **计算效率低**：求解一个 **n**元方程组需要计算 **n**+**1**个 **n**阶行列式。当 **n**增大时，计算量呈阶乘级增长，时间复杂度为 **O**(**n**⋅**n**!)，远高于高斯消元法等直接解法。因此，在实际数值计算中，尤其对于高阶方程组，很少采用克莱姆法则。
  * **适用条件苛刻**：必须满足方程个数等于未知数个数且系数行列式不为零。

### 💎 总结

克莱姆法则为我们理解线性方程组的解提供了一把直观的“钥匙”，尤其在理论分析中地位重要。但在实际求解规模稍大的方程组时，通常会选择计算效率更高的算法，如**高斯消元法**。
